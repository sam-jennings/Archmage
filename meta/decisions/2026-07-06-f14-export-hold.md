# 2026-07-06 — F14 Card export and printed-deck timing

Source: `_review/ARCHMAGE_SAM_DECISIONS_F3_F14_2026-07.md`, §F14.

## Decision

**Hold.** Do not regenerate exports or order new prints. Continue using the existing
**5×20 + 4 Print & Bind deck** as a flexible prototype (pull only the cards a given test
needs). No plans to change this physical deck in the near future.

The printed deck is a **practical prototype asset, not canon.** Current canon is 4×15 +
wilds (2–4p) and 5×15 + wilds (5–6p); the oversized P&B deck supports testing by
excluding unused cards and must not be read as current deck canon.

**Allowed:** use the existing P&B deck; pull required cards; make temporary paper
inserts / player mats / reference cards / AT sheets; make clearly-labelled non-canon test
aids. **Not allowed:** regenerating `export-cs3/` or `export-printenbind/` as if rules
are final; new print runs; treating 5×20 + 4 as canon; updating card text that depends on
F1/F3/F6/F8/F10 without decision-file propagation.
