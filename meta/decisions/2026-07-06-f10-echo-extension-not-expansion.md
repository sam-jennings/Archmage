# 2026-07-06 — F10 Product scope and Echo framing

Source: `_review/ARCHMAGE_SAM_DECISIONS_F3_F14_2026-07.md`, §F10.

**Amends the Decision Register's F10 framing** (which carried working-hypothesis A:
2–4p primary band, Echo as a held expansion).

## Decision

- 5–6p **Echo is an extension of the base system, not an expansion module.** Use the word
  **extension**, not expansion, for Echo.
- **2–4p and 5–6p Echo have equal design priority for now.** Echo is not demoted to
  expansion status while unconfirmed; it is also not claimed as confirmed.
- **Product packaging remains undecided** (Echo in the base game vs packaged separately
  later) — that is a product/manufacturing call, not a design-priority call yet.

## Sequencing (unchanged intent, new framing)

F1 still contaminates F2, because Echo confirmation criteria include counter
comprehension. So: don't claim Echo confirmed while F1 is unresolved; don't demote Echo
while F1 is unresolved; run the counter/capacity test in the cleanest environment, then
run 5–6p Echo + AT with the chosen/leading F1 model. Best sequence: (1) F1
comprehension/structure test, (2) 5–6p Echo + AT test, (3) compare whether both count
bands deliver the same product promise.

## Canon delta

None — process/framing change; game content unchanged.
