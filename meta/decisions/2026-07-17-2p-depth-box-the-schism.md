# 2p depth is a box — The Schism

## Change

Answers the expansion audit's Part-2 open question ("is 2p depth base-game territory or a box?") with a split, chosen by Sam 2026-07-17:

1. **2p health is base-game territory, free** — the Rival's Gambit contention layer (Array=3, Living-Array take-rule + safety valve, optional take-and-bury and Source tranches, opt-in Trials/Veiled Power) stays base-side per the deep dive. Don't sell the fix.
2. **2p depth is a box** — a new dedicated 2-player expansion, **The Schism** (`expansion/the-schism/Expansion - The Schism (v0.1).md`), core hook chosen by Sam: **contested draft/market** — cut-and-choose Collection over the dying Source (the Rift / Severing / Severance / Tithe), with a Tier-2 Rift-card deck. The line's first count-gated module.

## Same-day amendments (Sam's review, 2026-07-17)

Three calls made reviewing the first draft, folded into the module as iteration-log entries B11–B13:

- **The Tithe** (B11): each Rift, the severer sets 1 revealed card into the Arcane Reserve before splitting — fixes Drought starvation (the Reserve is otherwise fed only by the binding and scarce 2p TF discards while the Rift shortens the main game); the Last Schism reveals 2/round (base consumption rate) so the Drought runs *longer* than base 2p.
- **Open-information identity** (B12): the Schism is deliberately an open-information duel — Rift income is public, depth comes from acting on the read. The veiled-core fix was offered and **rejected**; forced hand-reveal effects stay banned.
- **Severance carries initiative** (B13): one token — the holder chooses the shares AND leads the round. Reverses the first draft's fixed-turn-order split (confusing; first-turn value under the Schism is small: Array access for cast exchanges + the end boundary).
- **Calibration: reveal 4 / tithe 1 / sever 3** (B14, Sam's challenge): reveal-3/sever-2 was chosen for income parity but guts the cut (two options; 1/1 freezes the token). Scratch clock comparison: reveal-3's only edge was ~0.9 main-game rounds; the Drought-share problem is fixed on the consumption side instead (Drought = reveal 3 / no tithe / sever 3 → ~41% of rounds vs base ~29%). Open cost logged: main game ~6.5 rounds, ~23% fewer casting phases than base — the headline playtest question.

## Why

The audit (2026-07-16) identified 2p-dedicated depth as the one genuinely unowned axis — arguably the most common real-world count, with multiple modules weakest at 2. The deep dive's finding that dedicated 2p games design the head-to-head market as its own object points at cut-and-choose rather than scaling the Array down. Keeping the health fixes free avoids "the base game is broken at 2 without the box."
