# Decision

For the 2p strategic-depth work (Rival's Gambit package):

1. **Ascension Trials will be developed for 2p, but will NOT become the default 2p
   endgame.** Some players don't enjoy the Trials; standard evaluation stays the
   default at all counts. This closes the `[decide]` flagged in
   `_review/2P_STRATEGIC_DEPTH_DEEP_DIVE_2026-07.md` §3/§9.
2. **Veiled Power is an optional rule attached to the Trials endgame** — available
   for those who play Trials at 2p, not part of the base 2p mode.

## Why

Player-preference: forcing the Trials teach and structure on every 2p table
excludes players who prefer the simpler evaluation. The 2p base package must
therefore stand on the contention layer alone (Array=3 + Living-Array take-rule,
optional denial/tranches), with Trials + Veiled Power as the opt-in depth layer.

## Consequence for the package

The deep dive's §9 warning applies: with standard evaluation, the base 2p mode's
excitement rests entirely on main-loop contention — so the contention levers carry
more weight in testing, and the endgame-predictability fix only reaches Trials
tables. Acceptable trade per Sam.

## Canon delta

None — no vocabulary, version, or structural canon facts change; this scopes an
exploration/proposal.
