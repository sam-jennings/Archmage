# Stranger playtest plan — one printed set

Draft for Sam. No session with strangers has been run yet (the French six-player test was
prepared but never played). This plan gets one stranger session onto the calendar with the
kit that exists today, and makes that session also count as the first v3.2 playtest (2026-11-13: v3.1 was approved by designer decision as rulebook v3.2, so there is no confirm/kill verdict any more).

## 1. The constraint: one printed set

One set is enough for **one table in person** — which is all a first session needs. The set
only limits two things: running **two tables at once** (e.g. a meetup with eight players), and
**sending a game away** for a blind test without Sam. Neither is needed for session one.

Check the set before the day: the existing Print & Bind deck (5×20 + 4) is a prototype, not
canon — pull the 2–4p cards (four energies, 1–15, plus the wilds) and leave the rest in the
box. The **A3 board PDF is pre-v3.1** (old Enchantment scores, retired "Opening" step — QUEUE
P2). For an in-person v3.1 game, print the v3.1-patched board image
`card-design/export-screentop/board/board-a3-150dpi-v31.png` instead, and have the online
reference (`web-apps/archmage-reference.html`) on a phone or tablet. Counters: any 20 tokens.

## 2. Three routes

| Route | What it is | Sam's effort | Cost | Gives |
|---|---|---|---|---|
| **(a) In person, Sam silent** | Sam hosts with the one set, 2–3 strangers, Sam only points at the written text (blind teach, grade (b) in the evidence plan) | Find a venue/group, ~2.5 h on the day | Travel + a drink; reprint nothing | Best observation: faces, hesitations, table talk, a real replay choice |
| **(b) Online, Screentop** | The fully built table `@samjennings/Arcane-Drought` (2–4p, v3.1: deck on the Source, Array, 20 counters, 4 seats). Recruit through Break My Game's weekly sessions, their Discord, or a BGG Works-in-Progress thread | One solo dry-run on the table, a post a week ahead, ~2 h per session | Free | Highest volume; strangers anywhere; easy to repeat weekly. Weaker: less body language, platform friction mixes with rules friction |
| **(c) Second set (print-and-play)** | Print the existing deck file again (`card-design/export-printenbind/`) as-is, plus the v3.1 board image | Print + cut, or one order | Home printing, or a print order | Parallel tables, or a copy to lend to a friend who hosts without Sam (the cleanest replay signal) |

Notes:
- **Tabletopia is on hold** (Sam, 2026-11-13). Route (b) uses Screentop only.
- **Route (c) and F14.** The F14 hold (`meta/decisions/2026-07-06-f14-export-hold.md`, canon)
  forbids *regenerating* exports and *new print runs*, and allows "temporary test aids". A
  home-printed copy of the unchanged deck file looks like a test aid; ordering a new printed
  deck is a new print run and needs Sam to lift F14 for it. Either way: reprint as-is, no
  card-text changes.
- (a) and (b) need nothing new. (c) is only worth it once a second table or a lend-out is
  actually planned.

## 3. Recommended first session — doubles as the first v3.2 playtest

- **Route:** (b) Screentop, or (a) in person if Sam has a group within reach — both work with
  what exists. Pick by the open questions in §6.
- **Players:** 2–4 (Sam may play one seat online; in person he observes). At least one player
  who knows rummy-style games.
- **Rules:** rulebook v3.1 **baseline, clean** — 2–4p deck, no Echo, no Array Attunement, no
  Ascension Trials. Array Attunement only in a second game or a later session.
- **Teach:** no verbal teach. Players get the rulebook + online reference. Sam answers only by
  pointing at the line ("it's here"). Never ask "did you like it?".
- **Length:** ~2–2.5 h: 15 min reading, one full game, then the replay choice.

Note fields for the session log, on top of the v3.1 criteria table in the template:

**TS1 — blind teach**
- Minutes from opening the rules to the first turn (target under 15).
- Counter questions per player in the first 3 turns (target 0–1 after the read).
- Rules looked up, verbatim; silent misplays (rule, self-corrected y/n).
- Each time Sam had to point at text: topic.

**TS2 — replay choice**
- After game one, the neutral ask only: *"We've got time for one more — this again, or
  something else?"* Have a short familiar card game ready as the real alternative.
- The choice; who argued for it; any "next time I'd…" statement, verbatim.
- How players describe the game in one sentence, verbatim.

## 4. Recruiting steps

1. **Solo dry-run** on the chosen table — Part A of the session template (~60–90 min). Online:
   confirm a guest can join the Screentop room and see their own hand only.
2. **Write one ask** (from the logistics doc): *"Unpublished card game, ~45 min, looking for
   people who like rummy-style games to try it cold and show me where it confuses them."*
3. **Post it.** Online: Break My Game's weekly-session sign-up (a week ahead) and Discord; a
   BGG WIP thread with the Screentop link. In person: one local game night or café (Sam to name).
4. **Confirm 2–3 players** for one date; ask permission to take notes (and to record, if
   online); names become P1/P2/P3 in the log.

## 5. Session day checklist

- [ ] Table ready: deck shuffled on the Source, Array of 5, 20 counters, seats (online: room
      link tested).
- [ ] Rulebook v3.1 + online reference link ready for each player.
- [ ] Session log open: copy Part B of
      `meta/experiments/vnext-scoring-economy/dry-run-and-session-template.md` to
      `playtests/YYYY-MM-DD-session-05.md`; add the TS1/TS2 fields above.
- [ ] Note the start time of the rules read.
- [ ] Familiar alternative game ready for the replay choice.
- [ ] After: 2-minute player form (rules clarity 1–5, want to play again 1–5, one-sentence
      description); log same week; every ACTION copied to `meta/QUEUE.md`.

**What to record:** the template's four v3.1 criteria (Transfiguration built during play,
end-game RESHAPE control, low-end integer scores, Enchantment pursuit), the per-player end
state, every rule lookup, the TS1/TS2 fields, and `category: strangers`, `new_players:`,
`location:` in the front-matter (fields proposed in `pitch/PLAYTEST_EVIDENCE_PLAN.md`).

## 6. Open questions for Sam

1. **In person or online first?** Screentop is ready today; in person needs a venue.
2. **Where are you based, and which venues or groups can you reach?** (The evidence plan
   lists Amsterdam venues — confirm whether those apply.)
3. **How many strangers** for the first session — 2 (a 3-seat game with you) or 3–4?
4. **Will you play a seat**, or only observe? Observing gives cleaner TS1 data.
5. **Anyone who could host without you** later, with a second (printed) copy?
6. **Route (c):** home-print a second copy as a test aid, or lift F14 for a print order — or
   neither until needed?
7. **Is one session enough to CONFIRM v3.1**, or only to kill it? (Open in the template too.)
