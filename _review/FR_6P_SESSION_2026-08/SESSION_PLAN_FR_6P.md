# Six-player French session — the plan

## 1. Why this session is worth running

The `rules-and-teaching` thread's goal is *"players can learn, play, and track the game
from written materials alone — no verbal patching."* Every session so far has needed
verbal patching, so the goal has never actually been tested — you were always available
to rescue a confused player, and you always did.

**Remove the shared language and the rescue channel closes by itself.** You cannot patch
in English. That converts a soft discipline ("try not to explain") into a hard constraint,
which is the only way this hypothesis gets a clean test. Session 4 (Denise, 2026-07-06)
gave one data point that the *online* reference teaches the counter loop with zero
explanation. This session is n=4 under materially harder conditions.

The four French speakers are not a problem to work around. They are the strictest test
panel the project has had access to.

**Second prize, still valuable:** a 6-player Echo game. Echo is `under test` in
`canon.yml` and has never been played at full count. The 5-card Enchantment tier
(+5 counters, 16 RP) is *only* reachable here — you have literally never seen one in play.

## 2. What this session is NOT

**It is not the v3.1 confirm/kill.** That P1 is the top of the queue and it is tempting to
collapse the two, but they fight each other: v3.1's confirm criteria were written for
2–4p, four new players generate enormous noise, and the Echo deck changes the very
economy v3.1 is trying to measure. Confounding them would waste the confirm/kill rather
than accelerate it — run that clean on Tabletopia as planned.

You will still get *free* v3.1 signal (Transfiguration uptake, whether scores read
sensibly, enchantment pursuit). Record it as observation, not verdict. That's the one
heads-up; it's your call.

## 3. Configuration — decided in advance, do not change on the day

| | |
|---|---|
| Players | 6 (you + host + 4 new) |
| Deck | 5–6p: five energies incl. Echo × 1–15 (75) + 4 wilds = **79 cards** |
| Deal | 7 each · Array 5 face-up · rest = Source |
| Starting counters | **2 each** (5–6p) |
| Opening | each player binds 1 card to the Arcane Reserve, simultaneously |
| Rules version | v3.1 baseline |
| Variants | **none** — no Array Attunement, no Ascension Trials |

**Expect a short game in rounds.** 79 − 42 dealt − 5 Array = 32 in the Source, against six
players drawing at least once each per round plus Conjuration bonuses. The Source likely
empties in ~4 rounds; the Released Reserve (6 bound cards + the Array + discards) runs
maybe 3 more. Plan for ~7 rounds. Teaching time will exceed play time — which is fine,
because teaching is what you're measuring.

### Check before the day

- [ ] The prototype deck can actually field **five energies incl. Echo, 1–15, plus 4 wilds**. The current stock is the oversized print-and-bind set (export regeneration is on hold per F14) — pull the 79 and sleeve them as one deck now, not on the afternoon.
- [ ] **~40 counters.** Six players starting at 2, plus a 4-card Enchantment (+3) or a 5-card (+5) each, escalates fast. Running out mid-game destroys the counter-loop observation, which is the primary measurement.
- [ ] Print **6 copies** of the French reference (one per player, including you — you will be reading it too, and that models the behaviour).
- [ ] The French reference open on **two phones** at the table. Session 4's evidence is that the *screen* reference taught cleanly; give it a fair chance alongside paper.
- [ ] The A3 board printed. Its zone labels are in English — this is deliberate and handled in the materials (see §5).
- [ ] A phone propped up recording **audio** of the table, with everyone's agreement. You will be playing and cannot write everything down. The tone of a confusion is often more informative than the fact of it.

## 4. Running order — a ~3 hour block

| Time | What | Who |
|---|---|---|
| 0:00 | Setup while people arrive. Cards, board, counters visible. | You |
| 0:10 | **The framing** — host reads the framing script aloud in French. | Host |
| 0:15 | **Silent read, 8 minutes.** Everyone reads the reference sheet. Nobody speaks. Phones allowed for the screen version. | All |
| 0:23 | **First comprehension probe** (before any explanation) — see §6. | Host asks, you tally |
| 0:30 | **Open-hand demo round.** One full round, all hands face-up, played slowly. No commentary beyond naming the phase. | All |
| 0:50 | **The real game.** | All |
| 2:10 | Scoring. | All |
| 2:25 | **Debrief** — feedback sheets first (silently, individually), then discussion. | Host translates |
| 2:50 | Stop. Put a normal published game on the table. | — |

The demo round is where most of your data comes from. Play it face-up and slowly, and
resist narrating — the temptation to explain is strongest exactly when the information
you want is being generated.

## 5. The core discipline — and why the language barrier is your instrument

**The rule for the afternoon: help is pull, never push.**

Nobody explains anything unless a player asks. When a player asks, the host answers at the
*lowest tier that works*:

| Tier | Response | What it means |
|---|---|---|
| **0** | Player resolves it themselves from the sheet, no question asked | The materials work |
| **1** | Host silently **points** at the relevant line on the reference sheet | The information is there but not findable — a *layout/legibility* defect |
| **2** | Host reads the line aloud, verbatim, no elaboration | The information is there but not *comprehensible as written* — a *wording* defect |
| **3** | Host explains in their own words, beyond the text | The materials do not contain a workable explanation — a **rule or teaching-model defect** |

Your job while playing is to make one tally mark per event, with the topic and the tier.
That grid is the session's finding. **Tier 3 events are the headline result**: each one is
a specific, located failure of "learn from written materials alone," and each one earns a
QUEUE item.

Brief the host on this before anyone arrives — it is the one thing that must not be
improvised. Give them the tier card at the top of the teaching script.

**Your own discipline:** you do not explain, gesture, mime, or slide a card meaningfully
towards someone. You play, and you play a deliberately ordinary game — do not demonstrate
the optimal line, because a table of new players will copy you and you will have taught
strategy instead of measuring comprehension.

**About the board's English labels.** The board, and probably the cards, say *The Source*,
*The Array*, *Arcane Reserve*. The materials therefore keep every word that is physically
printed on a component in English, with a French gloss on first use only. Translating the
zone names would send players hunting a French word that doesn't exist on the table. This
is also a small, real finding in itself: watch whether the English labels cause any
hesitation, because that is exactly what a non-English-speaking customer would hit.

**One piece of luck worth knowing:** the game's vocabulary is Latin-rooted almost
throughout. Conjuration, Transfiguration, Enchantement, Transmutation Parfaite, Rappel —
they are cognates, near-identical in French. If comprehension fails, it will not be because
the words were foreign. That makes the result cleaner than you'd expect.

## 6. Comprehension probes — ask these, don't wait for them

Three moments, three questions. The host asks; you record who answers correctly, in order,
before anyone confers.

**Probe A — after the silent read, before the demo (0:23).**
> *« En un mot : que faites-vous pendant votre tour ? »*
> (In one word: what do you do on your turn?)

Looking for: collect → cast → learn. Not the words, the shape.

**Probe B — end of the demo round.**
> *« Vous avez 2 jetons. Vous lancez 2 sorts. Combien d'actions d'apprentissage vous
> reste-t-il ? »*
> (You have 2 counters. You cast 2 spells. How many learning actions do you have left?)

Correct answer: **2** — the Recall returns them all. This is F1, the counter loop, the
question that has failed in Sessions 1 and 3 and succeeded in Session 4. It is the single
most important data point of the afternoon. Record all six answers individually.

**Probe C — the first time anyone completes an Enchantment.**
> *« Vous venez d'apprendre cet Enchantement. Pouvez-vous utiliser sa capacité
> maintenant ? »*
> (You've just learned this Enchantment. Can you use its capacity now?)

Correct answer: **no, from the start of your next turn.** This is F3, enchantment timing,
which the rulebook flags as abusable if misunderstood.

## 8. What you're watching for, beyond comprehension

- **The counter loop (F1).** Does anyone forget the Recall and short-change their own learning phase? Does anyone try to spend the same counter twice? Note whether they learned it from paper or from the phone version.
- **Enchantment timing (F3).** Anyone using new capacity the turn they gained it.
- **The 5-card Enchantment.** First sighting ever. Does anyone go for it? Does +5 counters break the turn open in a way that isn't fun for the other five?
- **Six-player downtime.** Time one full round in the middle of the game. Watch whether people are looking at their hand or at their phone while waiting.
- **The Drought transition.** Does the table understand the game has changed phase without being told? This has never been observed with new players at all.
- **Transfiguration uptake** (v3.1 signal, observation only).
- **The English zone labels** — hesitation, wrong-pile errors, asking what a word means.

## 9. It's still a party

Four people came for a board game afternoon with a friend, not for a lab. Non-negotiables:

- The host frames it as *"Sam is designing this and needs to find its problems"* — a shared activity with a purpose, not an exam. People are far more willing when they know the goal is to break it.
- Explicit permission to stop: *"if it's not fun after one game, we stop and play something else."* Say it out loud at the start; it buys honesty later.
- Have a known, published, language-light game ready to go on the table at 2:50 regardless of how it went. Ending on someone else's polished game is how you get invited back.
- The feedback sheets go around **before** the group discussion, filled in silently. Otherwise the first opinion spoken becomes the table's opinion, and with a translation layer that effect is even stronger.
